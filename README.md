# تطبيق مشرفي ورواد شركة DXN العالمية

تطبيق مخصص لإدارة الأعضاء، النقاط، المنتجات، والفيديوهات القصيرة لفريق شركة DXN.

## هيكل المشروع
- الواجهة والتطبيق: سيتم ربطهما لاحقاً.
- التوثيق وإدارة المهام: تتم مباشرة عبر GitHub Issues وProjects.

## طريقة البدء
1. تابع قسم الـ Issues لمتابعة المهام المطلوبة.
2. استخدم فروع التطوير المعتمدة (main / develop).
